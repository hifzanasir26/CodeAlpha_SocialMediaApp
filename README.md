# CodeAlpha Social Media App

A social media web application developed using **Laravel 12**, **PHP**, **MySQL**, and **Bootstrap** as part of my CodeAlpha Full Stack Development Internship.

## Features

- User Registration and Login
- Create and Manage Posts
- Like and Comment on Posts
- User Profiles
- Profile Photo Upload
- Follow and Unfollow Users

## Technologies Used

- PHP
- Laravel 12
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Blade Templates

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hifzanasir26/CodeAlpha_SocialMediaApp.git
   ```

2. Open the project folder:
   ```bash
   cd CodeAlpha_SocialMediaApp
   ```

3. Install PHP dependencies:
   ```bash
   composer install
   ```

4. Install frontend dependencies:
   ```bash
   npm install
   ```

5. Create your environment file:
   ```bash
   copy .env.example .env
   ```

6. Generate the application key:
   ```bash
   php artisan key:generate
   ```

7. Configure your database in `.env`, then run:
   ```bash
   php artisan migrate
   ```

8. Start the development servers:
   ```bash
   php artisan serve
   npm run dev
   ```
